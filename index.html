💾 SQL Server Row-Level Security (RLS)

Dữ liệu được bảo vệ tự động ngay tại tầng Database Engine:

-- Security Predicate cô lập Tenant & Phòng ban
CREATE FUNCTION Security.fn_tenant_predicate(@TenantId INT)
RETURNS TABLE WITH SCHEMABINDING AS
RETURN SELECT 1 WHERE @TenantId = CAST(SESSION_CONTEXT(N'TenantId') AS INT);

CREATE SECURITY POLICY Security.TenantFilter
ADD FILTER PREDICATE Security.fn_tenant_predicate(TenantId) ON dbo.Kpis;

Liên kết Hai Chiều: Task ↔ KPI/OKR Tự Động

🔗 Cơ Chế Gán Trọng Số Đóng Góp

Mỗi Work Item gắn liền với mục tiêu chiến lược của công ty:

// Entity WorkItem liên kết trực tiếp
public class WorkItem {
  public int Id { get; set; }
  public int? KeyResultId { get; set; }
  public int? KpiId { get; set; }
  public decimal ImpactWeight { get; set; } // Tỷ trọng %
}

⚡ Tự Động Đồng Bộ Tiến Độ Realtime

  • Khi task chuyển sang Done, Event Handler tự động kích hoạt.
  • Tính toán lại tổng tiến độ Key Result dựa trên tổng trọng số hoàn thành.
  • Cập nhật Dashboard của ban giám đốc mà không cần người làm báo cáo.

📊 So Sánh Hiệu Quả Trước vs Sau

Trước (Zalo/Excel):
• Task một nơi, KPI một nẻo
• Cuối tháng vắt chân lên cổ làm báo cáo
• Dễ ngụy tạo số liệu
Sau (NEXTGEN):
• 100% Task gắn với Mục tiêu
• Tiến độ đồng bộ từng phút
• Số liệu thực chứng, minh bạch
