Kiến trúc AI-Native

Từ Legacy Gemini → Enterprise AI Architecture

❌ Trước đây (Legacy)

  • Gọi trực tiếp Google Gemini API từ Controller
  • Trả text tự do, không kiểm soát hallucination
  • Tự bịa điểm xác suất (PotentialScore)
  • Lưu raw prompt/response vào database
  • Thiếu kiểm tra quyền dữ liệu server-side
  • Gửi PII (email, SĐT) sang model AI

✅ Hiện tại (AI-Native)

  • Model Gateway IAIModelClient — DeepSeek V4 flash
  • Server-driven Grounding: Server tự sinh context, filter TenantId + ACL
  • Strict JSON Schema: Output cấu trúc chặt chẽ, có sourceIds
  • Abstain: Từ chối trả lời khi thiếu bằng chứng
  • Human-in-the-loop: AI tạo Draft → Người duyệt → Áp dụng
  • Không bao giờ gửi PII sang model

Động cơ Tính điểm & State Machine Check-in

🔄 State Machine Vòng Đời

  • Draft Nhân viên chuẩn bị số liệu
  • Submitted Nộp lên Review Queue
  • Reviewed Quản lý duyệt & cho điểm
  • Finalized Đóng kỳ, chốt điểm bất biến
  • Bảo vệ dữ liệu: Chặn hoàn toàn việc chỉnh sửa lén lút khi đã duyệt.

📐 Công thức Trọng số Đa tầng

Điểm tổng hợp phản ánh chính xác đóng góp thực tế:

FinalScore = ∑ (Score_i × Weight_i)
với ∑ Weight_i = 100%
// Tự động validate ranh giới
if (target == 0) return 0;
score = Math.Min(actual / target, 1.5);

🏆 Thang Đánh Giá 7 Bậc

  • Xuất sắc: ≥ 95% (Thưởng tối đa)
  • Tốt: 85% – 94%
  • Khá: 75% – 84%
  • Đạt: 60% – 74% (Hoàn thành chỉ tiêu)
  • Cần cải thiện: 50% – 59%
  • Yếu: 40% – 49%
  • Kém: < 40% (Cảnh báo sa thải)

💾 SQL Server Row-Level Security (RLS)

Dữ liệu được bảo vệ tự động ngay tại tầng Database Engine:

-- Security Predicate cô lập Tenant & Phòng ban
CREATE FUNCTION Security.fn_tenant_predicate(@TenantId INT)
RETURNS TABLE WITH SCHEMABINDING AS
RETURN SELECT 1 WHERE @TenantId = CAST(SESSION_CONTEXT(N'TenantId') AS INT);

CREATE SECURITY POLICY Security.TenantFilter
ADD FILTER PREDICATE Security.fn_tenant_predicate(TenantId) ON dbo.Kpis;

Liên kết Hai Chiều: Task ↔ KPI/OKR Tự Động

🔗 Cơ Chế Gán Trọng Số Đóng Góp

Mỗi Work Item gắn liền với mục tiêu chiến lược của công ty:

// Entity WorkItem liên kết trực tiếp
public class WorkItem {
  public int Id { get; set; }
  public int? KeyResultId { get; set; }
  public int? KpiId { get; set; }
  public decimal ImpactWeight { get; set; } // Tỷ trọng %
}

⚡ Tự Động Đồng Bộ Tiến Độ Realtime

  • Khi task chuyển sang Done, Event Handler tự động kích hoạt.
  • Tính toán lại tổng tiến độ Key Result dựa trên tổng trọng số hoàn thành.
  • Cập nhật Dashboard của ban giám đốc mà không cần người làm báo cáo.

📊 So Sánh Hiệu Quả Trước vs Sau

Trước (Zalo/Excel):
• Task một nơi, KPI một nẻo
• Cuối tháng vắt chân lên cổ làm báo cáo
• Dễ ngụy tạo số liệu
Sau (NEXTGEN):
• 100% Task gắn với Mục tiêu
• Tiến độ đồng bộ từng phút
• Số liệu thực chứng, minh bạch
